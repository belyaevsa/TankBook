## What to build

### 1. Seed pack and catalog engine – ALREADY LANDED
Do not rewrite either. Your only change here is the `years` open-end sentinel described above
(`0` → `null`, plus the decoder). Two invariants they already satisfy, which you must not break:

- **Offline on day one**: the pack is bundled, so suggestions work with no network. **Nothing on this
  screen may require the network.**
- **The decoupling rule**: catalog values are *suggestions* copied into the `Vehicle` row.
  **No `Vehicle` ever references a catalog id**, so a catalog correction never mutates a user's garage.

### 2. The Add car screen
Per the artboard: name, make/model with suggestions, powertrain picker, odometer, home currency
**pre-filled from locale** (RU locale → ₽; see the JOURNEYS row), units, optional tank size, optional car
photo. Selecting a suggestion pre-fills tank capacity / battery size / fuel kinds, and **every pre-filled
value stays user-overridable**.

Save writes a `Vehicle` through the existing repository and exits per SCREENMAP.

### 3. The three error states – exact copy from `docs/ERRORS.md`
| Condition | Shows | Next step |
|---|---|---|
| Name empty on save | Warn underline on Name: "Give the car any name – you can change it later." | Type; save re-enables live |
| Odometer missing/implausible (e.g. 12 km on a 2015 car) | Warn: "That's the total distance the car has driven – check the dashboard." | Fix · confirm it's right (one tap – new cars exist) |
| Catalog lookup offline | Hint: "Suggestions unavailable offline – you can fill tank size later in Garage." | Continue manually; nothing blocks |

Rules that apply to all three (CLAUDE.md rule 7): **every error names its next step**, and every error
**survives being ignored** – "confirm it's right" is one tap, because a genuinely new car does read 12 km.
Never block save on the odometer warning. No monetization anywhere on this screen.

### 4. Localization
Every user-facing string goes into `Localizable.xcstrings` with **EN and RU**. No hardcoded text
(hard rule 10). The error copy above is EN; supply a faithful RU translation.
