## What to build

### 1. Detection
When the extracted or chosen currency differs from the vehicle's home currency, the sheet enters
the foreign state. Detection comes from the extraction when present and from the user's chip
choice otherwise – never from the device locale alone, which is wrong for a traveller.

### 2. The conversion card
Per `design/screens/ConfirmForeign.dc.html` (the authority): the original amount, the converted
home amount, and the rate with its date. **Never silently convert on low confidence** – if the
currency is uncertain, say so and let the user pick; a wrong currency silently converted is a
number the user cannot spot later.

### 3. Rate cache + seed pack
- A local cache keyed `(date, base, quote)`, matching `SCHEMA.md`.
- A **bundled seed pack** so a first launch with no network still converts common pairs.
- Lookup uses the **entry's `rateDate`**, not today. A fill-up dated last month converts at last
  month's rate, and re-opening it next year must produce the identical number.
- **A miss is not an error.** It saves as **rate-pending** (F9): the original amount is exact,
  the home amount is absent, and the entry is complete enough to save. Backfill later fills
  blanks only and **never overwrites an existing snapshot** (hard rule 3).

### 4. No network in this task
Provide the fetcher as an injected protocol with a test double, exactly as `ConfigStore` does.
Do not implement HTTP; that lands with the sync work.

## Tests

1. **Pending-rate save**: a foreign fill-up with no rate available saves, is complete, and shows
   as pending. Assert the saved `Money` has an exact original amount and a nil `homeAmount`.
2. **`rateDate` is the entry date, not today**: date an entry in the past, assert the rate looked
   up is that date's. This is the invariant hard rule 3 exists for.
3. **Snapshots are immutable**: backfill fills a blank, and a second backfill with a *different*
   rate leaves an existing snapshot untouched.
4. **Determinism**: converting the same entry twice yields byte-identical results.
5. **Seed pack**: with no network and no cache, a common pair still converts.
6. **Never silently convert on low confidence** – assert the UI asks rather than guessing.
7. **Decimal, not Double**: a rate like `4.3287` and an amount like `289.50` round-trip exactly;
   `Decimal(double:)` must appear nowhere.
8. **L4**: the ConfirmForeign layout renders; the ordinary sheet is unchanged when the currency
   matches home.

### Vacuous-assertion traps
`#expect(true)`; asserting a conversion happened without asserting the value; a "pending" test
that never checks `homeAmount` is nil; testing `rateDate` with today's date so the bug cannot
show; comparing money with `Double` equality.
