## The three rules this screen exists to honour

1. **`JOURNEYS.md` F6a - nothing is written until the user confirms.** The server returns
   *candidates* and commits nothing; this UI is the review. The preview follows **F7's rule, not a
   progress bar: trust is re-established with numbers, not a checkmark.** The headline figure is the
   **derived consumption**, because a driver knows their own average - `8.2 L/100km` reads as right
   or wrong instantly where "220 rows parsed" does not.
2. **`JOURNEYS.md` F6b - a flagged row is fields, not a line of CSV.** Parsed, labelled values with
   the marker on **only the field that is wrong**. A missing value stays **blank, never `0`**. The
   raw line lives behind "Original row" for the rarer case where the *mapping* is wrong.
3. **`ERRORS.md` → Import wizard - the user declares the format; the app never sniffs it.** The
   supported list comes from **`GET /import/formats`**, server-driven.

## Tests

`cd ios && swift test` is **742**; `xcodebuild test` on **`iPhone 17`** is **135**. Run both first,
record the real numbers, and both must rise.

1. **Nothing is written before confirm** - with the preview on screen, assert the repository is
   **unchanged**. This is the whole point of the screen.
2. **The preview's consumption comes from the same engine** that computes it after commit - compute
   both and assert **equality**. A display-only figure means the user approved a number they never
   saw (F6a).
3. **Cancel deletes the stored parse and writes nothing.**
4. **The format list is rendered from the transport's response**, not a constant - script two
   different lists and assert the UI follows. **A hardcoded list passes every other test and
   silently defeats the architecture.**
5. **A wrong declared format (`422`) shows the specific message**, never a generic failure (F7).
6. **Offline**: the import entry point says why, and the rest of the app is unaffected (hard rule 1
   - the exception is the parse only).
7. **A flagged row renders labelled fields**, and a missing value renders **blank, not `0`**.
8. **RU**: the plural strings render correct forms at **1, 2, 5, 11, 21** (11 takes `many`, 21 takes
   `one`).

### Vacuous-assertion traps named for this task

- A hardcoded format list (test 4).
- Asserting the preview's **labels** rendered without asserting the **values** - that is how a
  display-only figure ships.
- A "nothing written" test that never opens the repository.
- Asserting a view exists without asserting its text - the classic way a localization bug stays
  green.
- `#expect(true)`, or asserting only that a call did not throw.
