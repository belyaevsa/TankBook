## The copy rule, and it resolves a real conflict

**There is no Pro tier. Every user has full access** (product owner, 2026-08-27). So the honest
message is **version-first, never an upsell**: *"this needs a newer version of Tankbook"*, with
**update** as the next step. Never "go Pro", never a price, never a tier name.

That is also what keeps hard rule 7 intact - *"monetization appears in no error surface except the
car-limit sheet"* - and `docs/API.md` forbids an upsell mid-capture. A tier-shaped message here
would violate a hard rule **and** be false.

## Where it goes, and where it must not

`docs/SYNC.md` → **The Settings sync surface (normative)** is the authority. The status row is
**reassurance, never a warning**: it does not turn amber with age, and a long queue is not an error
state. Read that section before choosing a treatment.

- **It goes on the passive account/status row in Settings** (`SettingsView.accountCard`).
- **Never a modal, never a toast at sync time** (hard rule 8: conflicts and waits surface where the
  data lives, never as a modal at sync time).
- **No screen is ever sync-gated** (hard rule 1). Nothing about this blocks any part of the app.
- **Nothing is lost**: a refused push leaves the queue dirty and re-pushable, exactly as S7 does.
  The row says what is waiting, not that something failed.

## What each state should say (decide the exact copy; these are the meanings)

| outcome | meaning | next step |
|---|---|---|
| `.upgradeRequired` (426) | this app is older than the server's minimum; **pull still works** | update the app |
| `.tierRefused` (402) | the server gated something this client cannot do | update the app |
| `.refused(status:)` | an unknown gate from a newer server | update the app; do **not** invent a reason |
| `.rateLimited(retryAfter:)` | a **wait**, not a failure | it retries itself; say when, if the server said |
| `.transportUnavailable` | S7, already handled | unchanged - do not touch this path |

**`.rateLimited` is not the same kind of thing as the other three** and must not read like a
failure: nothing is wrong, the server asked for a pause. If you collapse all four into one message
you have thrown away the distinction the core half exists to make.

## The blind spot that has shipped SIX times

Read the top of `ios/App/Sources/Localization/L10n.swift`. **`Text(_: String)` does not localise** -
a string *literal* is a `LocalizedStringKey`, an **interpolated `String`** is not, and the gate
cannot tell them apart because no key is missing. Two instances shipped this week, both
`Text("\(number) km")`. If you render a retry delay or a status code by interpolation, that is
exactly the shape.
