## The defect

At Dynamic Type **XL**, Home's RU stat-tile label renders **«РАСХОДЫ ЗА А…»** while EN's
"AUGUST SPEND" fits. Russian runs 20-30% longer and **short strings expand worst**.
`docs/DESIGN.md` → Accessibility floor makes full Dynamic Type support non-negotiable, so a
clipped label is a **floor violation, not a cosmetic nit**.

phrase is also how P1.4 shipped "АВГУСТ РАСХОДЫ" - word-order nonsense - so if you touch the
composition at all, read `docs/LOCALIZATION.md` first. **Prefer not to touch it**: the catalogue is
another lane's this run.

## The vacuous trap, named in the row itself

**Asserting a label's text through the accessibility tree proves nothing.** XCUITest reads the
string the view was *given*, not the pixels it *drew*, so a clipped label passes such an
assertion. This is the same class as `OdometerFormatTests` staying green while the separator had
no glyph and the odometer rendered unseparated for all of P1.

So: an XCUITest may assert **geometry** (a label's frame fits inside its container, a row wraps to
two lines), never merely that the text exists. **The real gate is the screenshot, read by a human** -
the orchestrator opens every one.
