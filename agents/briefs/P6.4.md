### The sentence this screen must not say

`DELETE /account` is a **tombstone**. A revoked device gets `410` on its next pull, and **the user's
log stays on their phone**. The screen must never imply local data is deleted, because it is not -
and a user who believes it is will not trust the export that still works. `https://tankbook.live/delete-account/`
already states the true version in both languages; match it.

## Vacuous-test traps, named

- Asserting a label's text via the accessibility tree - XCUITest reads what the view was given, so a
  wrong string still "matches" whatever you assert about it. Assert the **behaviour**.
- `isHittable` does not model occlusion on this project: an element under the save bar reports
  itself hittable, and "tapping" it hits the bar.
- A navigation test that passes because the screen never appeared and the assertion was on absence.
