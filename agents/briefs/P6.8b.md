## The distinction that decides every call site

**Background vs user-initiated.** Low Power Mode postpones **opportunistic** work only:

- launch / foreground / timer sync cycles
- attachment upload and prefetch
- the rate pack refresh
- the catalog pack fetch

It changes **nothing** a user asked for. A save, a manual "Sync now", an export, a capture, an
import the user started - all proceed exactly as before, Low Power or not. If you find yourself
deferring something the user just tapped, the wiring is wrong.

Pass `.background` at the launch, foreground and timer triggers. Leave every user-initiated path
alone.
