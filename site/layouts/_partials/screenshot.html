{{- /* The only path to an on this site. Params: name (explicit filename in assets/screenshots, never a glob), alt (a real description), eager (optional bool, above-the-fold only). A missing resource, an empty alt, or alt="screenshot" fails the build. W12: screenshots are 1206 px phone captures rendering into slots that top out at 336 CSS px (layout.css .hero__shot; every other slot is 260-300). Serving the source was 1600 KB on the landing page alone. Everything now ships resized - 336/672 (1x/2x) WebP with the same-size PNG as the fallback, per docs/SITE.md (responsive images, WebP + PNG fallback, srcset). Narrower slots reuse the same files; 336 px into a 260-300 px slot is single-digit waste next to 1206 px into it. */ -}} {{- $name := .name -}} {{- $alt := .alt -}} {{- if not $name -}} {{- errorf "screenshot partial: no filename given" -}} {{- end -}} {{- if not $alt -}} {{- errorf (printf "screenshot %s: alt is empty - every screenshot carries a description" $name) -}} {{- end -}} {{- if eq $alt "screenshot" -}} {{- errorf (printf "screenshot %s: alt is the literal word \"screenshot\" - describe what the image shows" $name) -}} {{- end -}} {{- $res := resources.Get (printf "screenshots/%s" $name) -}} {{- if not $res -}} {{- errorf (printf "screenshot %s: not found in assets/screenshots - check the explicit filename" $name) -}} {{- end -}} {{- $png1x := $res.Resize "336x" -}} {{- $png2x := $res.Resize "672x" -}} {{- $webp1x := $res.Resize "336x webp q85" -}} {{- $webp2x := $res.Resize "672x webp q85" -}}
